NEON GALLERY
============

CARA PAKAI:
1. Buka folder ini.
2. Masukkan foto kamu ke folder "assets".
3. Beri nama foto: foto1.jpg, foto2.jpg, dst.
4. Buka index.html di browser.

MENAMBAH FOTO:
Buka script.js lalu tambahkan:
{src:"assets/foto13.jpg", title:"Foto 13", category:"travel"}

Kategori:
portrait
nature
travel
other

TIDAK PERLU SERVER.
Bisa langsung dibuka dengan klik dua kali index.html.

Catatan:
Jika nama file mengandung spasi, gunakan nama file sederhana seperti foto13.jpg.
