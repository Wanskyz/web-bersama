MY CREATIVE SPACE — PREMIUM 3 AVATARS

Fitur:
- 3 avatar di Hero: kiri, tengah (utama), kanan
- Neon ring, glow, orbit, spark, floating animation
- Background particle canvas
- Aurora glow dan glassmorphism
- Scroll reveal animation
- SociaBuzz, Saweria, Discord
- Karya dan creator friends
- Tombol musik
- Responsive desktop/tablet/mobile
- Tanpa admin/database

CARA GANTI 3 AVATAR:
1. Buka folder assets.
2. Ganti avatar-left.svg dengan avatar kiri kamu.
3. Ganti avatar-center.svg dengan avatar utama kamu.
4. Ganti avatar-right.svg dengan avatar kanan kamu.

Jika memakai JPG/PNG, kamu juga bisa:
- masukkan avatar-left.jpg / avatar-center.jpg / avatar-right.jpg
- lalu ubah nama file pada index.html di bagian <img src="...">.

CARA GANTI MUSIK:
- Masukkan file MP3 milik kamu ke assets/.
- Ganti nama file pada index.html:
  <audio id="bgMusic" loop src="assets/music-placeholder.mp3"></audio>

CARA MENJALANKAN:
- Ekstrak ZIP.
- Buka index.html di browser.

EDIT LINK:
- SociaBuzz, Saweria, Discord, Instagram, TikTok, YouTube ada di index.html.
- Data karya dan teman ada di script.js.
